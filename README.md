# Hotel_Booking_Analysis
## Project Overview
This project analysis hotel Booking data using python,sql,and Data Visualizuation techniques.
## Tools Used
- Python
- Pandas
- SQLite
- Matplotlib
- Google Colab

  Analysis performed
  - Data Cleaning
  - Missing Value Handling
  - Duplicate Removal
  - Hotel- wise Booking Analysis
  - Cancellation Analysis
  - Monthly Booking Trends
  - Market Segment Analysis
  - Country Analysis

    ## Key Findings
    - City Hotel received the highest booking.
    - August and July were the busiest months.
    - Portugal generated the highest bookings.
    - Online Travel Agents generated the most bookings.
